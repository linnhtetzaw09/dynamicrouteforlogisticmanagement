#  Logistics Manager

- Public marketing site (Home / About / Vision & Mission)
- Register + Login (new users start as **Pending**)
- Admin approval workflow (only approved users can access staff features)
- CRUD for Sites, Vehicle Types, Vehicles, Jobs
- Admin-only CRUD for Employees (staff accounts)
- Reports & search (job status, site-based views, vehicles per site, jobs per origin site, etc.)
- Random jobs add

## Tech
- PHP 7.x 
- MySQL / MariaDB
- Bootstrap 5 (CDN)
- jQuery + AJAX + JSON (CDN)
